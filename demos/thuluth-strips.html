Thuluth strips

Thuluth behind the script interface: a line comes back as a vector strip of exactly the width asked, so the composition engine can set it in any band. It widens the thuluth way, one long kashida per word (after a tooth letter where it can, as in بســم), then the word gaps; below its natural width it declines (that needs stacking). The dashed box is the strip; vowels appear in the band when the letter style shows all marks.
